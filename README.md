
# Reverse Engineering Challenges

A collection of writeups and detailed comments for reverse engineering challenges, covering analysis techniques, solutions, and learning insights.

## Overview

This repository contains comprehensive writeups for various reverse engineering challenges, including:
- Binary analysis and disassembly
- Vulnerability identification
- Exploit development
- Tool usage and techniques

## Contents

- `writeups/` - Challenge writeups with step-by-step solutions
- `comments/` - Detailed comments and notes on techniques (in progress)
- `tools/` - References to useful RE tools (in progress)

## Getting Started

Each challenge desription file includes:
- Problem description
- Solution approach
- Key insights and lessons learned

## Learning Resources

- [Ghidra](https://ghidra-sre.org/) - NSA reverse engineering tool
- [x64dbg](https://x64dbg.com/) - Debugger
